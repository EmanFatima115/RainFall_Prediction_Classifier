# Rainfall Prediction Classifier 🌧️

## Project Overview
The Rainfall Prediction Classifier is a machine learning project that uses weather data to predict rainfall. It demonstrates data preprocessing, feature preparation, model training, and classification techniques.

## Objectives
- Prepare and clean weather data.
- Perform feature selection and preprocessing.
- Train machine learning classification models.
- Evaluate model performance.
- Save the trained model for future predictions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

## Machine Learning Models
The project explores classification approaches, including:
- Logistic Regression
- Random Forest Classifier

## Project Structure

```text
RainFall_Prediction_Classifier/
│
├── main.py
├── weather AUS.csv
├── rainfall_model.pkl
└── .gitignore
```

## Dataset
The project uses `weather AUS.csv` as its weather dataset.

The dataset contains weather-related information used for rainfall classification.

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/EmanFatima115/RainFall_Prediction_Classifier.git
```

**2. Open the project folder**

```bash
cd RainFall_Prediction_Classifier
```

**3. Install required libraries**

```bash
pip install pandas numpy scikit-learn
```

**4. Run the project**

```bash
python main.py
```

## Saved Model
The trained machine learning model is saved as:

`rainfall_model.pkl`
